# Visual Storyboard — Professional Legacy Edition

**Version:** v1.0  
**Date:** 23 September 2026  
**Project:** From Mapping to Decision  
**Phase:** Phase 5 Narrative Reset  
**Purpose:** Define what the reader should *see* before defining the interface.

---

# 1. Visual principle

The article should feel like an **interactive research atlas grounded in field practice**.

The dominant visual vocabulary is:

**maps + field photographs + structure photographs + annotated sections + selected evidence graphics**

—not cards, pills and dashboard widgets.

The layout may change from movement to movement.

There is no requirement for one sticky map to remain on screen through the entire article.

# 3. GWRPZ map palette

Avoid traffic-light red / yellow / green.

Recommended scientific sequence:

- **Low:** muted sand / stone — `#C8B79B`
- **Moderate:** blue-green — `#68AAA7`
- **High:** deep teal — `#0E716E`

Purpose:
- reads as a thematic hydrogeological surface;
- does not imply danger / warning;
- aligns with the wider research identity.

Final colours must be checked for:
- contrast;
- colour-blind accessibility;
- visibility under vector overlays.

# 5. Movement-by-movement storyboard

## Movement 1 — The question that stayed with me

### Primary visual
A strong full-width composition using:
- final GWRPZ / study-area cartography;
- restrained terrain / drainage texture;
- minimal article title;
- author line.

Optional:
a faint scan / thumbnail of an early research map or the earlier GWRPZ guide cover placed as a provenance artifact.

### Interaction
Very light:
- subtle parallax / layer reveal if performance allows;
- no controls in the hero.

### Reader takeaway
“This is an authored body of work.”

## Movement 2 — From research to practice

### Primary visual
A horizontal / vertical visual timeline with **real artifacts**, not icon cards.

Possible sequence:

**Postgraduate research**
→ **early GWRPZ guide**
→ **field application since 2019**
→ **Sabarkantha implementation**
→ **current evidence re-analysis**

### Assets
Available now:
- earlier GWRPZ guide cover;
- present GIS maps.

Needed:

- early field / professional images where appropriate.

### Interaction
Hover/tap can reveal:
- date / period;
- one-sentence meaning.

## Movement 3 — Sabarkantha as the working landscape

### Primary visual
Full-width study-area map.

Layers:
- villages;
- drainage;
- structures;
- boundary/context.

### Side evidence
Use editorial numerals directly on whitespace:

**58 constructed structures**  
**49 villages represented**

Do not place them inside four equal dashboard cards.

### Secondary visual
One or two real field images if available.

---

## Movement 4 — Building the spatial evidence

### Primary visual
An exploded / stacked map sequence.

The reader scrolls through:
1. aquifer;
2. slope;
3. drainage density;
4. lineament density;
5. LULC.

Each layer occupies the visual field.

Beside each, only:
- factor name;
- weight;
- one field question.

Example:

**Aquifer · 30%**  
*What subsurface setting may support storage and movement?*

### Avoid
- five mini-cards;
- long factor definitions;
- repeated “what this does not mean” copy.

## Movement 6 — When the map meets the ground

This is the visual centre of the article.

### Scene A — Structures on GWRPZ

Map:
- final GWRPZ;
- 58 structure points;
- village boundary faint.

Use a small analytical annotation:

**26 Moderate · 32 High**

No yellow caveat box.

---

### Scene B — Hydrological position

Map:
- drainage order highlighted;
- structures visible;
- selected example structure(s).

Visual annotation:
- lower-order drainage concentration;
- order distribution.

Optional:
small ridge-to-valley section diagram.

---

### Scene C — Lineament / subsurface context

Use **two linked visuals**:

1. map showing structures + lineaments;
2. conceptual hydrogeological section.

Conceptual section should show:
- ground surface;
- recharge structure nearby;
- weathered zone;
- fractured bedrock;
- mapped structural zone / fault-fracture;
- possible preferential groundwater movement.

Do not visually imply that every mapped lineament is an active recharge conduit.

Caption language:
“Conceptual hydrogeological interpretation; field verification is required.”

Statistics:
- closest;
- median;
- farthest nearest-lineament distance.

Keep exact 0/58 geometry coincidence in Method.

## Movement 7 — From map to construction

### Primary visual
Use real project images if available.

4. technical survey / design;

7. completed structure;

# 11. UX should follow the visuals

After this storyboard is approved, the UX specification should be designed around the actual visual forms.

Do not force every movement into the same card + sticky-map component.

The final experience can mix:
- full-bleed visual chapters;
- scrollytelling map moments;
- editorial long-form sections;
- image sequences;
- an interactive explorer;
- collapsed method drawers.
