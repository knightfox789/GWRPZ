Interactive groundwater recharge planning · Sabarkantha, Gujarat

Map the potential. Then make the decision.

GIS can narrow a search area, compare landscape evidence and make planning assumptions visible. It cannot decide a recharge site by itself.

Prototype purpose: validate narrative order, map states, evidence placement and responsive behavior before Phase 6. The maps use the validated Phase 4 web-data package.
01 · CONTEXT

Start with the landscape, not the structure.

Groundwater recharge planning begins by reading where water can enter, move through and be stored in the subsurface. The GWRPZ map is a screening layer inside that wider decision.

Recharge potential is not final site suitability.

02 · WHY LOCATION MATTERS

The same structure can sit in very different settings.

Aquifer conditions, slope, land cover, drainage and structural context vary across space. A structure type should not be selected before those conditions are screened.

This article does not claim that any existing structure underperformed; measured performance data are not part of the current evidence base.

03 · READ THE LANDSCAPE

Follow the drainage from upper catchment to larger channels.

Stream order provides one way to describe hydrological position. It helps separate upper-catchment recharge settings from locations closer to higher-order drainage.

04 · FIVE CONTROLS

Build recharge potential from five pieces of evidence.

30%Aquifer
20%Slope
20%Drainage density
15%Lineament density
15%LULC

No single factor is sufficient on its own. Factor scores are inputs to a weighted screening model.

05 · WEIGHTED MODEL

Combine the evidence, but keep the uncertainty visible.

Aquifer 30 + Slope 20 + Drainage Density 20 + Lineament Density 15 + LULC 15. The reconstructed score is reproducible over the five-input common domain.

The full historical Class 1/2/3 break rule is not fully recoverable. The article uses the supplied final GWRPZ raster as the class reference.

06 · READ THE GWRPZ

Potential is a relative class, not a permission to build.

Low, Moderate and High describe the supplied final recharge-potential classes. They do not guarantee recharge, structure success or universal suitability.

07 · POTENTIAL ≠ SITING

Add hydrology, structural context and field evidence.

Move from a potential map to a siting decision by adding drainage position, structural evidence, intervention purpose and direct verification.

Technical detail placement

Keep the caveat near the claim. Move the machinery deeper.

Why use the supplied final GWRPZ raster?

The weighted model was reconstructed, but the full historical Class 1/2/3 break rule could not be recovered exactly. The supplied final GWRPZ raster remains the final-class reference.

How is stream order assigned to structures?

From the nearest mapped drainage feature, with nearest distance retained. This is not presented as literal point-on-stream topology.

What is the reproducible lineament relationship?

Nearest mapped lineament distance. No defensible present/absent proximity threshold is documented, so the historical binary field is not treated as literal intersection.

What belongs in the full methodology appendix?

Input layers, scoring, weights, common-grid reconstruction, geometry repair, class-recovery uncertainty, structure QA, source lineage and limitations.
